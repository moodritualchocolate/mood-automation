# Consistent Character Engine

## Continuity controls
- same face
- same hair
- same body proportions
- same skin texture
- same wardrobe
- same accessories
- same location logic
- same lighting direction
- same product scale

## Shot tracking
Create a continuity sheet with:
- character description
- wardrobe
- hair and makeup
- expression range
- camera height
- focal length feeling
- location details
- product hand and orientation

Never allow a later shot to silently change identity or styling.
