# Web Research (competitor & pattern analysis)

Good design starts from evidence, not vibes. This skill studies how the best sites in a category actually work, separates real quality from trend noise, and turns it into principles you can build on — **without copying anyone's branding, assets, copy, or exact layouts.**

## Method

### 1. Choose a representative set
- Name **how many** sites and **why** (e.g. "8 sites: 4 direct category leaders, 2 adjacent premium DTC, 2 Awwwards winners for craft reference"). State the set explicitly — don't secretly sample 2 and generalize.
- For real breadth, **fan out**: one research agent per site (via the Agent/Workflow tools), each returning the structured observation below. This is the legitimate use of parallel agents — collect many independent reads, then synthesize.

### 2. Observe each site through a fixed lens (so sites are comparable)
For every site capture:
- **Structure / IA** — section order, page count, nav model.
- **Hierarchy** — what the eye hits 1st / 2nd / 3rd.
- **Density** — airy vs packed (the `taste` VISUAL_DENSITY read).
- **Type system** — display + body faces, scale, treatment.
- **Color** — palette, how accent is used, light/dark.
- **Motion language** — scroll behavior, reveals, transitions, restraint level.
- **Conversion devices** — CTA rhythm, proof placement, pricing presentation, trust signals.
- **Strongest thing** it does · **weakest thing** it does.

### 3. Separate signal from noise
- Distinguish a **genuinely effective pattern** (solves a real user/conversion problem) from a **trend / cargo-cult** copy (everyone does it because everyone does it). Call out which is which.
- A pattern appearing on 6/8 sites is a signal; a flashy effect on 1 award site may be noise for a commerce page.

### 4. Synthesize into PRINCIPLES, not layouts
- Output adoptable **principles**: "extract the interaction rhythm, visual hierarchy, density, motion language, and product-storytelling — translate the strongest into an original system."
- Explicit **DO-NOT-COPY list**: their branding, colors, logos, photography, copy, and pixel layouts are off-limits.

## Output format
1. **Comparison matrix** — sites × the lens dimensions above.
2. **Ranked principles to adopt** (most to least impactful), each tied to the evidence.
3. **Anti-patterns observed** (what the weak sites got wrong — avoid these).
4. **DO NOT COPY** list — specific to the studied set.
5. A one-paragraph **direction brief** the design skills can start from.

## Anti-patterns
- Copying a competitor's layout/branding instead of extracting principles (legal + brand risk, and it looks derivative).
- Sampling 2–3 sites and calling it research.
- Confusing "trendy" with "good".
- Studying only direct competitors — include craft references outside the niche.
