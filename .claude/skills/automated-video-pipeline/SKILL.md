# Automated Video Pipeline

## Workflow
1. Read the brief and brand assets.
2. Define target channel and format.
3. Build concept and storyboard.
4. Select generation model per shot.
5. Prepare source images.
6. Write production prompts.
7. Generate shots.
8. Inspect every shot.
9. Regenerate failed shots.
10. Edit sequence.
11. Match color and sound.
12. Add captions if needed.
13. Export required formats.
14. Create contact sheet and review notes.
15. Organize final files.

## Folder structure
project/

- 07_selected_clips

## Completion rule
Never report completion until all exports have been visually reviewed.
