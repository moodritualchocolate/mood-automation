# MOOD — UNIVERSAL GAME FLOW (source of truth)

> זו הזרימה הקבועה שכל רגע ב־MOOD מתלבש עליה. לא קשורה לרגע מסוים. מעל כל מסמכי המיפוי האחרים.
> נמסר ע"י המייסד. אין לסטות ממנו בלי אישור מפורש.

MOOD is not a questionnaire, card game, self-help app, or content feed.
Every Moment is a short cinematic emotional journey that leads the player away from the screen and toward one clear action in real life.

Feel: fast · cinematic · emotionally precise · deeply human · native in Hebrew · never preachy · never manipulative.

**Emotional movement:** Recognition → Emotion → Meaning → Choice → Real life → Honest return → Living memory
**Initial journey:** ~45–65 seconds (excluding real-life time).

## The 12 stages
1. **The Human Mirror** — one illustration + one short familiar behavior. Player: "נכון, זה גם אני." Begin inside the situation, ≤2 lines, phrase-by-phrase, virtue hidden. **CHOICE:** two honest identifications (e.g. "כן, גם לי" / "בדרך כלל אני בוחר אחרת") — neither morally superior.
2. **The Emotional Truth** — image changes meaningfully; expose the distance/need/fear beneath. Player: "לא חשבתי על זה ככה." One idea, no advice, no blame; describe the human truth, not the failure. Pause before the strongest line.
3. **The Future Echo** — NEW visual state (absent / farther / older / quieter). Message: "מה שמחכה לי היום לא בהכרח יחכה תמיד." Longing not panic, urgency not guilt. Very little text; the illustration carries it. **Usually the strongest beat.**
4. **The Quote** — AFTER the echo, BEFORE the decision. One short verified & attributed quote, quiet breath over the image, literary typeface, slow. Deepens, doesn't explain.
5. **The Principle** — one line answering "what does this Moment want me to understand?" Human language, no "lesson/insight" title. Virtue name may appear only if it strengthens.
6. **The Real-Life Choice** — one clear question: "להכניס את הרגע הזה ל־24 השעות הקרובות?" Primary: concrete commitment. Secondary: respectful alternative with EQUAL visual dignity. No vague labels ("המשך"), no guilt.
7. **The 24-Hour Commitment** — personal action name + one real behavior + visible 24h countdown + optional reminder (OFF by default, one-time, no guilt) + "added to your board." Max 5 active. This is where the Moment becomes a real-life game action.
8. **Exit to Life** — UI quiets, controls disappear. "עכשיו מניחים את המכשיר. החיים מחכים מחוץ למסך." One unmistakable action. No paragraph, no extra lesson, no competing buttons. Never pretend to know if they did it.
9. **My Board** — up to 5 open commitments; each: human title, moment's image/symbol, time remaining, reminder status, one clear RETURN action ("זה קרה — אני רוצה לספר"). Alive & game-like, not a productivity dashboard. Never "Complete/Done."
10. **Honest Return** — "כשהרגע הגיע — מה קרה הפעם?" Two EQUAL branches: "בחרתי אחרת" / "עוד לא". Chose differently → "מה השתנה כשבחרת להיות שם?" (optional free text). Not yet → "מה השאיר אותך במקום?" (recognizable choices + free text). Never "נכשלת / לא עמדת / איבדת התקדמות."
11. **The Second Chance** — if "עוד לא", preserve as open; next time recall their own words: "בפעם הקודמת סיפרת ש־״…״ השאיר אותך במקום. מה תרצה לבחור הפעם?" Remember to help, not accuse.
12. **Living Memory** — write a new entry into the Personal Book: moment, virtue, choice, player's words, date, open/closed. Ink appears progressively on the page (right page first, then left), literary handwriting, follows the page perspective — written INTO the book, not pasted. Reward = "משהו אמיתי בחיים שלי הפך לזיכרון חי." Not XP/badge.

## Emotional editing rules (every screen must pass)
1 idea per screen · understood in 2s · strongest line unmistakable · image advances the story · screen is necessary · next interaction feels inevitable · moves the player toward real life. If two consecutive screens say the same thing — combine or cut.

## Motion rules
Text word/phrase by phrase (not every letter at one slow speed) · pause before the emotional arrow · avoid constant zoom · use framing/light/absence/focus/composition changes · every state adds information · no decorative/carousel/spring motion · Reduced Motion = fades + immediate readable text.

## Final product test — the Moment succeeds only if the player feels:
> זה אני. · לא ראיתי את זה ככה. · הזמן הזה לא יחזור. · אני רוצה לבחור אחרת. · אני יודע בדיוק מה לעשות. · עכשיו אני מניח את הטלפון. · כשאחזור, אוכל לספר את האמת.

**The app does not complete the Moment. The player completes it in real life.**
