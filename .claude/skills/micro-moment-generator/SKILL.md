# Micro Moment Generator

Generate compact moments that communicate one feeling or action.

## Examples
- hand reaches for the pouch
- package opens naturally
- one piece catches the light
- subtle smile after tasting
- product placed beside coffee
- morning sunlight crossing the package
- pouch gently settling on a table
- chocolate piece rotating slightly in a hand

## Rules
- One action per clip.
- 2–5 seconds.
- Clear start and finish.
- Easy to loop when possible.
- No unnecessary camera complexity.
- Preserve product integrity.
