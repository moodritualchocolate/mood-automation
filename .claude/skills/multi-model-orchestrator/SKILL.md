# Multi-Model Orchestrator

Choose tools per shot rather than forcing one model to do everything.

## Selection criteria
- human motion quality
- product preservation
- camera control
- prompt adherence
- image-to-video consistency
- duration
- lip sync
- editing capability
- speed and cost
- commercial rights

## Output
For each shot provide:
- recommended model
- reason
- fallback model
- likely failure mode
- prompt adaptation notes

Never claim a model is best without considering the exact shot.
